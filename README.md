# 台风实况与分级预警平台

面向沿海居民的台风实况信息网站，集中展示台风名称、当前位置、移动方向、风力强度及分级预警，并提供清晰、易懂、适合手机查看的避险提示。

## 核心能力

- 台风名称与编号
- 当前经纬度、距附近城市或海岸线的距离
- 移动方向、移动速度与预测路径
- 中心最大风力、风速、中心气压
- 蓝、黄、橙、红四级预警及对应行动建议
- 地图路径、更新时间、数据来源和异常提示
- 移动端适配及弱网降级

## 建议启动顺序

1. 确认权威数据源及数据使用许可。
2. 确定首发覆盖地区和预警规则责任边界。
3. 制作移动端原型并开展沿海居民可用性测试。
4. 开发数据接入、地图展示、预警计算和通知能力。
5. 完成压力、弱网、无障碍和灾备测试后上线。

## 查看当前演示页面

当前仓库已包含零依赖的静态网站。由于页面需要读取 `data/typhoon.json`，请通过静态 HTTP 服务预览，或访问 GitHub Pages 部署地址。

数据抓取脚本位于 `scripts/fetch-typhoon.mjs`，数据来自浙江省台风路径实时发布系统。GitHub Actions 每 15 分钟检查一次上游数据，只有实况发生变化时才提交新的 JSON。

页面展示的风险等级是依据实况风力生成的辅助提示，并非官方预警；实际防灾行动必须以当地政府和气象主管部门发布的信息为准。

## 重要声明

本平台应明确标注数据来源及更新时间。预警信息必须以国家和地方气象主管部门正式发布内容为准；平台自行计算的风险提示只能作为辅助信息，不得冒充官方预警。
